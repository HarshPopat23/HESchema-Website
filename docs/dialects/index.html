Dialects and compatibility

Use the linked meta-schema URL as the root $schema. These dialects extend Draft 2020-12. The Python validator implements their custom keywords.

Dialect$schema URICustom keywords
Field Comparison v1field-comparison-v1.jsoncompareFields
Relationships v1relationships-v1.jsoncompareFields, uniqueKeys
Relationships v2relationships-v2.jsonAll v1 keywords plus aggregateCompare, localReferences
Relationships v3relationships-v3.jsonAll v2 keywords plus sortedBy, nonOverlapping
Relationships v4relationships-v4.jsonAll v3 keywords plus arithmeticEquals
ML v1ml-v1.jsontensorShapes

Experimental expressions

assertExpression requires a separate experimental evaluator. Each URI in the table selects only its documented native vocabulary.
