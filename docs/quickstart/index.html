Quickstart

Run the citation example with Python 3.11 or newer. Start at the root of the website checkout.

1. Install the validator

python -m venv .venv
. .venv/bin/activate
python -m pip install "heschema @ git+https://github.com/HarshPopat23/HESchema-.git@46df47ec05b962d0a7b4da574340fcdacec94c56"

On PowerShell, activate the environment with .venv\Scripts\Activate.ps1.

2. Validate the example

Save this as validate_example.py. The example’s root $schema selects the Relationships v2 dialect.

import json
from pathlib import Path
from heschema.schema import SchemaEngine

example = json.loads(Path("examples.json").read_text())["localReferences"]
engine = SchemaEngine()
for case in ("pass", "fail"):
    errors = engine.errors(example["schema"], example[case])
    print(errors[0]["instanceLocation"] if errors else "Valid")
python validate_example.py

Expected output

Valid
/citations/0

3. Start the live playground

python serve.py

Open http://127.0.0.1:8000/playground/. The server is for local development. To enforce custom keywords, use an evaluator that implements the declared HESchema dialect.
