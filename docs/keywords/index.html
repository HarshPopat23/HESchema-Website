compareFields

Compare two values in the same document.

Try in Playground
Native HESchema JSON

Schema

{
  "$schema": "https://raw.githubusercontent.com/HarshPopat23/HESchema-/main/src/heschema/field-comparison-v1.json",
  "type": "object",
  "compareFields": [
    {
      "left": "/min",
      "right": "/max",
      "operator": "lte",
      "mode": "number"
    }
  ]
}

Passing data

{
  "min": 2,
  "max": 2
}

Failing data

{
  "min": 3,
  "max": 2
}

Recorded error at (document root) Comparison 0 failed: '/min' lte '/max' (number)

Options and edge cases

Every rule supplies left and right JSON Pointers, an operator, and a mode. Numeric mode requires finite numbers and compares without coercion. JSON mode supports equality and inequality. Date mode compares calendar dates. Missing operands fail.

uniqueKeys

Require a distinct key or key tuple for every array item.

Try in Playground
Native HESchema JSON

Schema

{
  "$schema": "https://raw.githubusercontent.com/HarshPopat23/HESchema-/main/src/heschema/relationships-v1.json",
  "type": "array",
  "uniqueKeys": [
    "/sku"
  ]
}

Passing data

[
  {
    "sku": "A"
  },
  {
    "sku": "B"
  }
]

Failing data

[
  {
    "sku": "A",
    "price": 1
  },
  {
    "sku": "A",
    "price": 2
  }
]

Recorded error at /1 Item 1 has the same key as item 0

Options and edge cases

Pointers are relative to each item. All components together form one key. Missing values differ from explicit null, but two otherwise equal tuples with missing components still collide. Add required to enforce presence.

aggregateCompare

Compare declared values with array counts or sums.

Try in Playground
Native HESchema JSON

Schema

{
  "$schema": "https://raw.githubusercontent.com/HarshPopat23/HESchema-/main/src/heschema/relationships-v2.json",
  "type": "object",
  "aggregateCompare": [
    {
      "left": "/itemCount",
      "operator": "eq",
      "right": {
        "count": "/items"
      }
    },
    {
      "left": "/total",
      "operator": "eq",
      "right": {
        "sum": {
          "array": "/items",
          "item": "/minor"
        }
      }
    }
  ]
}

Passing data

{
  "itemCount": 2,
  "items": [
    {
      "minor": 7
    },
    {
      "minor": -2
    }
  ],
  "total": 5
}

Failing data

{
  "itemCount": 1,
  "items": [
    {
      "minor": 7
    },
    {
      "minor": -2
    }
  ],
  "total": 5
}

Recorded error at (document root) Aggregate comparison 0 failed (eq)

Options and edge cases

Each operand selects an integer, a count, or a sum of item values. Every rule must pass. Empty collections count and sum to zero. Missing pointers, fractions, booleans, and numeric strings fail.

localReferences

Require each citation to match exactly one included source.

Try in Playground
Native HESchema JSON

Schema

{
  "$schema": "https://raw.githubusercontent.com/HarshPopat23/HESchema-/main/src/heschema/relationships-v2.json",
  "type": "object",
  "localReferences": [
    {
      "source": {
        "array": "/citations",
        "keys": [
          "/sourceId"
        ]
      },
      "target": {
        "array": "/sources",
        "keys": [
          "/id"
        ]
      }
    }
  ]
}

Passing data

{
  "sources": [
    {
      "id": "report-1"
    }
  ],
  "citations": [
    {
      "sourceId": "report-1"
    }
  ]
}

Failing data

{
  "sources": [
    {
      "id": "report-1"
    }
  ],
  "citations": [
    {
      "sourceId": "report-9"
    }
  ]
}

Recorded error at /citations/0 Reference has no matching local target

Options and edge cases

Each side selects an array and an ordered list of item-relative key pointers. Both key lists must have the same length. Repeated source references can pass. Missing keys and duplicate target tuples fail, even if no source references the duplicate.

sortedBy

Check the order of array items by a selected key.

Try in Playground
Native HESchema JSON

Schema

{
  "$schema": "https://raw.githubusercontent.com/HarshPopat23/HESchema-/main/src/heschema/relationships-v3.json",
  "type": "array",
  "sortedBy": {
    "key": "/key",
    "mode": "number",
    "direction": "ascending",
    "ties": "allow"
  }
}

Passing data

[
  {
    "key": 1
  },
  {
    "key": 1
  },
  {
    "key": 2
  }
]

Failing data

[
  {
    "key": 2
  },
  {
    "key": 1
  }
]

Recorded error at /1/key Item 1 violates the ordering relative to item 0

Options and edge cases

Choose ascending or descending order and allow or forbid ties. The key is relative to each item. Even a single item needs a valid key. The validator checks submitted order and leaves the input untouched.

nonOverlapping

Reject overlapping intervals in an array.

Try in Playground
Native HESchema JSON

Schema

{
  "$schema": "https://raw.githubusercontent.com/HarshPopat23/HESchema-/main/src/heschema/relationships-v3.json",
  "type": "array",
  "nonOverlapping": {
    "start": "/start",
    "end": "/end",
    "mode": "code-point-offset",
    "bounds": "half-open"
  }
}

Passing data

[
  {
    "start": 3,
    "end": 5
  },
  {
    "start": 0,
    "end": 3
  }
]

Failing data

[
  {
    "start": 0,
    "end": 8
  },
  {
    "start": 2,
    "end": 4
  }
]

Recorded error at /1 Interval overlaps item 0

Options and edge cases

Select start and end relative to each item. Adjacent half-open intervals can share an endpoint. Closed intervals that share an endpoint overlap. Missing or reversed endpoints fail. Input order does not matter.

tensorShapes

Check tensor rank, axis lengths, and shared dimensions.

Try in Playground
Native HESchema JSON

Schema

{
  "$schema": "https://raw.githubusercontent.com/HarshPopat23/HESchema-/main/src/heschema/ml-v1.json",
  "type": "object",
  "tensorShapes": [
    {
      "path": "/embeddings",
      "shape": [
        "batch",
        3
      ]
    },
    {
      "path": "/labels",
      "shape": [
        "batch"
      ]
    }
  ]
}

Passing data

{
  "embeddings": [
    [
      1,
      2,
      3
    ],
    [
      4,
      5,
      6
    ]
  ],
  "labels": [
    0,
    1
  ]
}

Failing data

{
  "embeddings": [
    [
      1,
      2
    ]
  ],
  "labels": [
    0
  ]
}

Recorded error at /embeddings/0 Expected size 3 at axis 1, got 2

Options and edge cases

A numeric dimension fixes its length. A symbol binds a length across the declarations in the same assertion. Null leaves the length unspecified but still requires a rectangular tensor. An empty axis exposes no deeper lengths. Use standard items and type for numeric element requirements.

arithmeticEquals

Check supplied arithmetic results using exact decimal strings.

Try in Playground
Native HESchema JSON

Schema

{
  "$schema": "https://raw.githubusercontent.com/HarshPopat23/HESchema-/main/src/heschema/relationships-v4.json",
  "type": "object",
  "arithmeticEquals": [
    {
      "left": "/a",
      "right": "/b",
      "result": "/r",
      "operation": "add"
    }
  ]
}

Passing data

{
  "a": "0.1",
  "b": "0.2",
  "r": "0.3"
}

Failing data

{
  "a": "0.1",
  "b": "0.2",
  "r": "0.30000000000000004"
}

Recorded error at /r Arithmetic rule 0 failed (add)

Options and edge cases

Choose add, subtract, multiply, divide, or percentOf. A rounding rule can set the scale and mode. Numeric JSON tokens, exponent notation, and division by zero fail. The assertion validates the result without replacing it.

Specification and conformance cases

assertExpression

This is experimental documentation. The examples below illustrate proposed evaluator bindings. They require an expression evaluator and are outside the native dialects and playground in this release.

Structured JSON illustration
{
  "assertExpression": [
    {
      "<=": [
        {
          "var": "min"
        },
        {
          "var": "max"
        }
      ]
    }
  ]
}

The prefix operator takes two operands resolved from the current object.

CEL illustration
{
  "assertExpression": [
    "self.min <= self.max"
  ]
}

This assumes an evaluator binds self to the current object.

Both illustrate the rule that min must be less than or equal to max. With numeric fields, {"min": 2, "max": 3} passes and {"min": 4, "max": 3} fails. Coercion, missing values, diagnostics, and host functions depend on the evaluator. Use the native compareFields example for executable validation.
